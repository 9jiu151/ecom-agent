# 部署说明

本项目为「前端构建产物 + Node 服务」的一体化应用：只开一个端口，同时提供页面、接口、素材与导出图片。适合本地演示，也适合直接上云。

---

## 一、环境要求

| 项 | 要求 |
|---|---|
| Node.js | 18 及以上（开发使用 24.14） |
| npm | 9 及以上 |
| 内存 | ≥ 1GB（Banner 渲染在浏览器端完成，服务端压力很小） |
| 磁盘 | ≥ 200MB（含素材与历史图片） |
| 浏览器 | Chrome 100+ / Edge 100+ / Safari 15+ |

---

## 二、本地运行

```bash
# 1. 安装依赖（根目录 + 前端）
npm run setup

# 2. 构建前端
npm run build

# 3. 启动服务（默认 3000 端口）
npm start
```

打开 http://localhost:3000 即可。

开发模式（前后端热更新，前端 5173 端口，接口代理到 3000）：

```bash
npm run dev
```

## 三、公网部署

### 方案 A：云主机 + Docker（推荐用于正式演示）

仓库已附带 `Dockerfile`：

```bash
docker build -t ecom-agent .
docker run -d --name ecom-agent -p 3000:3000 \
  -v $(pwd)/data:/app/data \
  -v $(pwd)/outputs:/app/outputs \
  -v $(pwd)/uploads:/app/uploads \
  ecom-agent
```

- 访问 `http://服务器IP:3000`
- 三个挂载目录保证配置、历史记录、上传图片在容器重建后不丢失
- 如需域名与 HTTPS，前置 Nginx 反向代理到 3000 端口即可

### 方案 B：免费 PaaS（Render / Railway）

1. 将项目推送到 GitHub；
2. 在平台新建 Web Service，选择该仓库；
3. 构建命令：`npm run setup && npm run build`，启动命令：`npm start`；
4. 平台会自动分配公网域名，直接发给老师即可。

> 免费实例休眠后首次访问需要唤醒，建议演示前 5 分钟先打开一次。

### 方案 C：临时内网穿透（课堂演示，当前采用）

本地 `npm start` 后，用 cloudflared 将 3000 端口映射到公网：

```bash
cloudflared tunnel --url http://localhost:3000 --no-autoupdate
```

命令会输出形如 `https://xxx.trycloudflare.com` 的地址，直接发老师即可。特点是：
- 无需账号、无需域名，HTTPS 可直接访问
- 电脑与 `cloudflared` 进程必须保持运行；进程关闭或重启后地址会变化
- 适合课堂/评审临时演示，长期展示请用方案 A 或 B

本次已通过该方式发布；AI Key 已预置，公网访问无需任何配置，AI 接口带按 IP 限流。

## 四、AI 配置（已预置，打开即用）

本项目已在服务端预置真实模型，老师打开网站无需任何设置：

| 用途 | 服务商 | Base URL | 模型 |
|---|---|---|---|
| 文案生成 | DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| 图像生成 | 豆包 Seedream（火山方舟） | `https://ark.cn-beijing.volces.com/api/v3/images/generations` | `doubao-seedream-5-0-flash-260915` |

配置保存在 `data/settings.json`，Key 仅存服务端，前端只显示掩码。图像生成入口在 Banner 页「AI 背景（可选）」。

部署时也可用环境变量覆盖（优先于文件）：`AI_LLM_BASE_URL` / `AI_LLM_KEY` / `AI_LLM_MODEL` / `AI_IMAGE_BASE_URL` / `AI_IMAGE_KEY` / `AI_IMAGE_MODEL`。

若图像接口返回 `429 SetLimitExceeded`，表示火山方舟账号的模型用量限制已触顶或模型被暂停，需在控制台提高限额后重试；文案功能不受影响。

未配置或调用失败时全站自动运行在**规则模式**，所有核心功能可用。

## 五、目录与数据


## 六、常见问题

| 现象 | 原因与处理 |
|---|---|
| 3000 端口被占用 | `PORT=8080 npm start` 指定其他端口 |
| 页面空白 / 只有一行提示 | 未执行 `npm run build`，前端产物不存在 |
| 上传失败 | 文件超过 10MB 或不是 JPG/PNG/WebP |
| 导出图片有白底 | 商品图背景不是纯白，自动去底仅对白底图生效 |
| 中文素材路径乱码 | 项目已使用英文目录名（single/handbag 等），请勿改回中文目录 |
| 刷新后 404 | 服务已内置 SPA 回退；若使用 Nginx，需配置 `try_files $uri $uri/ /index.html` |
